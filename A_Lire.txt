Notre rendu prend la forme suivante:

Dossier Docs:

    Contient le document de Rendu en pdf
    Contient un sous-dossier avec tout les diagrammes présents dans le rendu

Dossier src/main

    Contient un sous dossier Kotlin avec le code source
    Contient un sous dossier resources avec les différentes textures qui ont permis de faire la map.

A la racine il y a le fichier pom.xml qui est un fichier de configuration java.
On trouve également le run.sh qui permet de lancer le jeu

Pour lancer le jeu sur les machines de l'école il faut lancer la commande suivantes à la racine du projet:

run.sh
