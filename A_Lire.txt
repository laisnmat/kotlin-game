Notre rendu prend la forme suivante:

Dossier Docs:

    Contient le document de Rendu en pdf
    Contient un sous-dossier avec tout les diagrammes présents dans le rendu

Dossier src/main

    Contient un sous dossier Kotlin avec le code source
    Contient un sous dossier resources avec les différentes textures qui ont permis de faire la map.
    Prévoit aussi les dossier permettant d'intégrer des sons etc

A la racine il y a le fichier pom.xml qui est un fichier de configuration java.

Pour lancer le jeu sur les machines de l'école il faut lancer les commandes suivantes à la racine du projet:

mvn install
mvn clean package (Génère dans un dossier target à la racine du projet)
java -jar @chemin_du_projet/target/tp-acvl-kotlin-1.0-SNAPSHOT.jar (Vous pouver récupérer l'adresse dans la sortie de la commande précédente)
